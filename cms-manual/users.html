วิธีใช้งานเมนู "ผู้ใช้งาน" (Users)

คู่มือสำหรับผู้ดูแลระบบ อธิบายการจัดการบัญชีผู้ใช้งานและสิทธิ์การเข้าถึง CMS

ภาพรวม สิทธิ์การใช้งาน การสร้างผู้ใช้งานใหม่ ฟิลด์ทั้งหมด 3 บทบาท (Role) มีอะไรบ้าง เคล็ดลับ
ภาพรวม

เมนู "ผู้ใช้งาน" คืออะไร

ใช้จัดการบัญชีล็อกอินเข้า CMS ทั้งหมด — กำหนดชื่อ, อีเมล/รหัสผ่านสำหรับล็อกอิน, บทบาท (role) ที่กำหนดสิทธิ์การเข้าถึงแต่ละเมนู และสาขาที่รับผิดชอบ (สำหรับผู้ใช้ที่ไม่ใช่ Admin)

Admin เท่านั้น

เมนูนี้จัดการได้เฉพาะ Admin เท่านั้น — Content Editor และ Medical Reviewer มองไม่เห็นและแตะต้องเมนูนี้ไม่ได้เลย แม้แต่การแก้ไขบัญชีของตัวเอง (ยกเว้นเปลี่ยนรหัสผ่านตัวเองตอนล็อกอิน)

สิทธิ์การใช้งาน

ใครทำอะไรได้บ้าง

Admin
  • สร้าง/แก้ไข/ลบผู้ใช้งานได้ทั้งหมด
Content Editor
  • แตะต้องเมนูนี้ไม่ได้เลย
Medical Reviewer
  • แตะต้องเมนูนี้ไม่ได้เลย
ขั้นตอน

การสร้างผู้ใช้งานใหม่

  1. เข้าเมนู ผู้ใช้งาน (Users) แล้วกด Create New
  2. กรอกอีเมลและตั้งรหัสผ่านชั่วคราวให้ผู้ใช้งาน (แนะนำให้ผู้ใช้เปลี่ยนรหัสผ่านเองหลังล็อกอินครั้งแรก)
  3. กรอกชื่อ (Name) — ใช้แสดงในระบบ
  4. เลือกบทบาท (Role) ให้ตรงกับหน้าที่ของผู้ใช้งานคนนั้น
  5. ถ้าเลือก Role เป็น Content Editor หรือ Medical Reviewer จะมีช่อง สาขาที่รับผิดชอบ (assignedBranches) ปรากฏขึ้น — เลือกสาขาที่ผู้ใช้คนนี้ควรเข้าถึงได้ (เลือกได้มากกว่า 1 สาขา)
  6. กด Save
ฟิลด์ทั้งหมด

รายละเอียดฟิลด์

ฟิลด์คำอธิบาย
ชื่อ (name) จำเป็นชื่อที่แสดงในระบบ CMS
อีเมล / รหัสผ่านใช้สำหรับล็อกอินเข้า CMS — จัดการผ่านระบบยืนยันตัวตนมาตรฐานของ Payload
บทบาท (role) จำเป็นเลือกจาก 3 แบบ: Admin / Content Editor / Medical Reviewer — ค่าเริ่มต้นคือ Content Editor เมื่อสร้างใหม่
สาขาที่รับผิดชอบ (assignedBranches)แสดงเฉพาะเมื่อ role ไม่ใช่ Admin — เลือกสาขาที่ผู้ใช้งานคนนี้เข้าถึง/แก้ไขเนื้อหาได้ ถ้า role เป็น Admin ช่องนี้จะถูกซ่อนไปเลย (Admin เข้าถึงทุกสาขาอยู่แล้ว)
อ้างอิง

3 บทบาท (Role) มีอะไรบ้าง

บทบาทขอบเขตการเข้าถึง
Adminเข้าถึงทุกเมนู ทุกสาขา ทุกสิทธิ์ — รวมถึงเมนูที่เมนูอื่นแตะไม่ได้ เช่น ผู้ใช้งาน, รางวัล/ผลงาน, และการลบ Leads
Content Editorแก้ไขเนื้อหาส่วนใหญ่ได้ (บทความ, แพทย์, โปรแกรม, สาขาที่ตนรับผิดชอบ) แต่เข้าถึงเฉพาะสาขาที่ถูกกำหนดใน assignedBranches เท่านั้น (ยกเว้นเนื้อหาที่ตั้งเป็น "ไม่ระบุสาขา" — เข้าถึงได้ทุกคน)
Medical Reviewerขอบเขตแคบกว่า Content Editor — เข้าถึงได้เฉพาะบางเมนู (เช่น แพทย์) ตามสาขาที่รับผิดชอบ ไม่สามารถแตะเมนู สาขา, รางวัล/ผลงาน, ผู้ใช้งาน ได้เลย
เคล็ดลับ

ข้อควรรู้เพิ่มเติม

เปลี่ยน Role ผู้ใช้เอง ทำไม่ได้

ผู้ใช้งานที่ไม่ใช่ Admin ไม่สามารถเปลี่ยนบทบาท (role) หรือสาขาที่รับผิดชอบ (assignedBranches) ของตัวเองได้ — ต้องให้ Admin เป็นผู้เปลี่ยนให้เท่านั้น เพื่อป้องกันการปรับสิทธิ์ตัวเองโดยไม่ได้รับอนุญาต

มอบหมายสาขาให้ครบ

ถ้าสร้างผู้ใช้งานเป็น Content Editor หรือ Medical Reviewer แล้วลืมกำหนด assignedBranches ผู้ใช้งานคนนั้นจะเข้าถึงได้เฉพาะเนื้อหาที่ "ไม่ระบุสาขา" เท่านั้น อาจทำให้มองไม่เห็นข้อมูลที่คาดว่าควรเห็น
